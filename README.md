# CampusMart

CampusMart is a MERN-based campus marketplace for students to buy and sell items within their campus community.

## Features

- JWT authentication
- Student marketplace listings
- Cloudinary image uploads
- Search and category/condition/price filters
- Ownership-based listing CRUD
- Structured offers
- Atomic offer acceptance and listing reservation
- Verified deal flow
- Buyer/seller handover confirmation
- Responsive React frontend

## Tech Stack

### Frontend
- React
- Vite
- React Router
- Axios
- Lucide React

### Backend
- Node.js
- Express
- MongoDB
- Mongoose
- JWT
- bcryptjs
- Cloudinary
